Converted to mono 44.1 kHz / 80 kbps MP3 for broad browser support, with 4ms attack and 12ms tail fades. Total audio size: 16,372 bytes. Page flicks are selected without consecutive repeats, with a subtle ±2% playback-rate variation. Per-recording gain keeps the effects quiet.
