# Deploy to Cloudflare Workers

This site builds to static HTML, JavaScript, CSS, and images in `dist/`. The root `wrangler.jsonc` tells Workers to serve that directory. Astro's Cloudflare adapter is not required: the site has no on-demand routes, sessions, or server-side APIs. Image optimization runs during the Astro build.

## Workers Builds settings

Use these settings for the connected Git repository:

| Setting | Value |
| --- | --- |
| Root directory | Repository root |
| Build command | `npm run build` |
| Deploy command | `npm run deploy` |
| Non-production branch deploy command | `npx wrangler versions upload` |
| Node.js | 22.12.0 or newer |

The Worker name is `sahajcv` in `wrangler.jsonc`. If the existing Cloudflare Worker has a different name, update that field to match it before deploying.

Commit `wrangler.jsonc`, `astro.config.mjs`, `package.json`, and `package-lock.json` before retrying the cloud build. Workers Builds installs the project's pinned Wrangler dependency. The deploy command uploads the files already generated by the build command.

## Local verification

```sh
npm ci
npm run deploy:check
```

`deploy:check` builds the site and runs `wrangler deploy --dry-run`; it does not publish a deployment. To check static routing and assets with the local Workers runtime after building:

```sh
npm run preview:workers
```

To publish from a locally authenticated Cloudflare account, run `npm run build` followed by `npm run deploy`.

## Why the original build failed

The deployment log enters Wrangler's `runAutoConfig` path, then loads `@astrojs/cloudflare`, whose prerendering code imports `renderForPrerender` from `astro/app`. The installed Astro version does not export it. This failure is in the adapter's build integration, before any site routes are generated.

Without a Wrangler configuration file, Wrangler detects Astro and can add the adapter automatically. Keeping an explicit static-assets configuration avoids that auto-configuration path. Do not add a Cloudflare adapter, Worker entry point, or Images/KV bindings for this static deployment.

References: [Astro's static Workers configuration](https://docs.astro.build/en/guides/deploy/cloudflare/), [Cloudflare's Astro guide](https://developers.cloudflare.com/workers/framework-guides/web-apps/astro/), and [Workers Builds settings](https://developers.cloudflare.com/workers/ci-cd/builds/configuration/).
