# Additional achievement artwork

Generated with the built-in `image_gen` tool (not the CLI). Original images remain in their generated-image directory. Final project assets use nearest-neighbor resizing and a 12-color indexed PNG palette with no dithering: 40×60 pixels for progress cards, 50×50 pixels for compact one-off badges. CSS uses `image-rendering: pixelated`.
