# Travel illustrations

Generated with the built-in imagegen tool. The shipped files are `public/images/travel/{petra,pyramids,taj-mahal,japan}.png`.

The user requested the same pixel density as the supplied architectural references: approximately 40×60 logical pixels per portrait panel. The generated illustrations were exported to exactly 40×60 pixels with nearest-neighbor resampling and a 12-color PNG palette without additional dithering. CSS `image-rendering: pixelated` preserves the grid when scaled. Only these small exports are included in the site; the larger generation originals remain outside the repository.
