# Achievement artwork

Generated with the built-in image generation tool. Each project asset is a 40 × 60 PNG, exported using nearest-neighbor sampling and a 12-color palette to match the Travel tiles. The original generated images remain in the Codex generated-images directory.

## wonders

Saved asset: `public/images/achievements/wonders.png`

Prompt:

Use case: stylized-concept. Create one full-bleed portrait pixel-art tile for a retro personal achievement journal. Aspect ratio exactly 2:3. It must look like artwork drawn on a very coarse 40 by 60 pixel canvas and enlarged with nearest-neighbor: big square pixels, clean stair-step contours, restrained checkerboard dithering, only 10-12 colors, no antialiasing, no fine texture. Same visual language as classic 1990s adventure-game scenic postcards. Strong readable silhouette at tiny size. The image fills the entire canvas edge to edge, NO border, NO frame, NO lettering, NO labels, NO progress indicators, NO UI, NO watermark. Subject: an evocative ancient-world travel scene, rose sandstone Petra Treasury facade in the foreground, tiny pale Taj Mahal dome and a stepped green mountain ruin in the far distance. A warm terracotta and dusty rose palette, violet shadows, pale peach sky. Monumental architecture, quiet sense of discovery. Keep architecture extremely simple and chunky.
